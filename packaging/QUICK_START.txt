Series Downloader 0.1.0-beta.2 — Windows x64

INSTALLER
Run SeriesDownloader-0.1.0-beta.2-windows-x64-setup.exe.
The installer works for the current user without administrator rights.
Launch Series Downloader from the Start menu.

ZIP
Extract the entire ZIP to a writable folder, then run SeriesDownloader.exe.
Keep the _internal folder beside the executable.

USING THE APP
Paste a series URL, click Scan Episodes, choose episodes and a save folder,
then click Download Selected. Downloads can be cancelled and resumed.
No Python, browser, or FFmpeg installation is required.

DATA AND UPDATES
Settings and library: %LOCALAPPDATA%\SeriesDownloader
Logs: %LOCALAPPDATA%\SeriesDownloader\logs
Default downloads: %USERPROFILE%\Downloads\SeriesDownloader
Updates and uninstall preserve settings, library, and downloaded media.
The ZIP build uses the same user profile as the installed build.

UPDATES
The app checks GitHub for new versions in the background on startup.
Click Updates at any time to check manually. A newer published version enables
Download update. After SHA-256 verification, click Install and restart.
Finish or cancel active downloads/cleanup before installing. Your settings,
library, and media are preserved. The app never installs an update silently
without the Install and restart action. The installer displays update progress.
The repository must have published release assets for an update to be offered.
Beta builds receive newer beta and stable releases; stable builds receive stable
releases. ZIP users can use the same update flow to install the new app per user.

This preview is not digitally signed. Check SHA256SUMS.txt to verify file integrity.
